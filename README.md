# She Can Foundation — Frontend Internship Project

A responsive, animated single-page website built for **She Can Foundation**, 
a Government-registered NGO (Indian Society Act, 1860) dedicated to 
empowering underprivileged women across India.

## 🛠️ Built With
- HTML5
- CSS3 (Animations, Flexbox, Grid)
- Vanilla JavaScript (Scroll Reveal, Counter Animation)

## ✨ Features
- Fully responsive design (mobile, tablet, desktop)
- Smooth scroll-reveal animations
- Animated impact counter
- Interactive photo gallery with hover effects
- Scrolling ticker banner
- Real content sourced from shecanfoundation.org

## 📋 Sections
- Hero Section
- Impact Statistics
- About the NGO
- Core Issue — Menstrual Hygiene Campaign
- Photo Gallery
- Programmes & Initiatives
- Donation Impact Calculator
- Founder Quote
- Call to Action
- Footer with real contact details

## 🏢 About She Can Foundation
She Can Foundation is a non-governmental organization registered under the 
Indian Society Act, 1860, dedicated to uplifting and empowering underprivileged 
women through education, training, free sanitary pads, dignity kits, and 
awareness workshops across India.
